## Известные проблемы
- Нативная сборка (`vite`, `tsc` 7, `electron-packager`) работает только на Windows владельца; в облаке/VM — обходной путь из `BUILD_RELEASE.md`.
- `git push` с Linux-VM владельца не проходит (прокси); пушить из облачной сессии или владельцу самому.
