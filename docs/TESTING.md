# Тестирование и проверка

Автотестов (unit) в проекте нет. Качество держится на трёх уровнях: типы → симуляция баланса → проверка в браузере. Все три — обязательны перед сдачей, если задача их касается.

## 1. Типы
`npm run typecheck` (= `tsc`). Ноль ошибок.
Если нативный `tsc` из `node_modules` не запускается (Linux-VM/облако, см. `BUILD_RELEASE.md`) — любой `tsc` 5.x с `"types": []` и объявлением `declare module '*.css'`.

## 2. Баланс: бот-симулятор
- `npm run sim -- <maxWave> <heroId|random> <runs>` — бот играет забеги подряд (Цитадель копится между забегами), печатает `GAME OVER on wave N`.
- Сравнение «до/после»: одинаковые параметры, **много прогонов** (разброс большой). Рекомендуемо: 6 серий × `sim 30 random 8` = 48 забегов на версию; сравнивать среднюю волну.
- `scripts/dbgm.ts '<json узлов>' <spells 0|1> <runs>` — баланс с заданными узлами Цитадели.
- Ориентир (2026-11-12, v0.12): бот в среднем доходит до волны **≈11–12** (6×8 забегов). Сильный сдвиг (±1 волна и больше) без намерения — повод разбираться.
- Бот кастует заклинания по позициям врагов относительно `WALL_X` — при смене раскладки поля поправить `sim.ts`/`dbgm.ts`.

## 3. Проверка в браузере (смоук)
Открыть `play.html` (или `npm run dev` → http://localhost:5199). Для автоматизации — Playwright: в консоли страницы доступны `window.game`, `window.ui`, `window.renderer`.

Чек-лист:
- [ ] Меню, «Новый забег», лагерь, старт волны, конец волны, поражение — без ошибок в консоли.
- [ ] Поле целиком на экране, ничего важного не закрыто HUD: 16:9 (1600×900), 21:9 (2560×1080), 5:4 (1280×1024), 4:3 (1024×768).
- [ ] Карты: лес, болото (туман), зима (замёрзшая река). Волна босса (5, 10, …) — ночь, полоса босса, телеграфы.
- [ ] Герои: стоят на постах, ближник выходит навстречу, стрелки за ним; никто не «замерзает» вдали от поста.
- [ ] Управление: клик по карточке героя выбирает (проверить 10+ кликов подряд, нажатие 80–170 мс), клик по земле — флажок и марш, клик по врагу — красная метка, Esc/ПКМ — отмена, «↺ на посты», F + клик — весь отряд, двойной клик по карточке при зуме — камера к герою.
- [ ] Заклинания Q/W/E/R (если открыты), прицел, отмена.
- [ ] Перезагрузка страницы: «Продолжить забег» работает, настройки сохранились.
- [ ] Оба языка: `localStorage['oplot-lang'] = 'en'|'ru'` в `addInitScript`; меню, Цитадель, лагерь, книга рецептов, карточки, событие, бой, поражение, настройки — нет русского в EN и наоборот, тексты не вылезают. Автоопределение: контекст Playwright с `locale: 'en-US'` / `'ru-RU'` без сохранённого ключа.

Полезные приёмы в Playwright:
- Быстрый старт боя: `game.newRun(); renderer.cam.home(); game.wave = N; game.startWave(); ui.paused = false; ui.speed = 2;`
- Нужный стартовый герой: `game.meta.upgrades.pick_start = 1; game.meta.startHero = 'warden';` перед `newRun()`.
- Отключить подсказки обучения: `localStorage.setItem('oplot.tut', JSON.stringify([...ключи]))`.
- Координаты экрана ↔ мира: `renderer.cam.toWorld()`; канвас логически 1280×720 (по высоте 720).
- Позиции DOM брать через `getBoundingClientRect()` в `page.evaluate` — `locator.boundingBox()` спотыкается о панель, которая перерисовывается 10 раз в секунду.
- `dist/index.html` (модули + `crossorigin`) по `file://` в Chromium не грузится — поднимать локальный http-сервер. `play.html` однофайловый, открывается по `file://`.
