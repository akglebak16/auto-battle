# Промпты для новых чатов

Копируйте и дополняйте своими деталями. Агент сам прочитает `CLAUDE.md` и `docs/`, но явная просьба не помешает.

## Продолжить работу
> Проект «Оплот: Осада» в `D:\games\castle-autobattler`. Прочитай `CLAUDE.md`, `docs/STATE.md` и `docs/LESSONS.md`, коротко скажи, где мы сейчас и что в бэклоге, и предложи следующий шаг.

## Задача / фича
> Прочитай `CLAUDE.md` и нужные документы из `docs/`. Задача: <что сделать и зачем>. Сначала посмотри игру и код, если вариантов несколько — предложи 2–3 с плюсами/минусами. Потом сделай, проверь по `docs/TESTING.md` (типы, бот-баланс, браузер на разных экранах) и обнови документы по протоколу самообучения.

## Баг
> Баг: <что вижу, где, как воспроизвести, на каком экране/карте/волне>. Сначала докажи причину (замер, лог, скриншот), потом почини, добавь урок в `docs/LESSONS.md` и проверку в `docs/TESTING.md`, если такое может повториться.

## Независимая экспертиза / ревью
> Сделай независимую экспертизу <механики / экрана / баланса>: посмотри игру глазами игрока, опирайся на код и замеры, сравни с лучшими играми жанра. Выдай выводы и план, ничего не меняя, пока я не скажу.

## Баланс
> Проверь баланс <волн / героя / предмета / Цитадели>: прогони `npm run sim` до и после (много серий), покажи цифры и предложи правки с обоснованием.

## Интерфейс
> UI-аудит <экрана>: проверь по `docs/DESIGN.md` (зоны экрана, цвета по смыслу, подсказки, перекрытия) на 16:9, 21:9, 5:4 и 4:3, со скриншотами. Предложи правки, затем сделай.

## Релиз
> Пересобери (`play.html`, `dist`, exe), обнови README («Что нового»), `docs/STATE.md`, закоммить и запушь в `main`.

## Обновить память
> Перечитай историю этого чата и обнови `docs/STATE.md`, `docs/LESSONS.md`, `docs/DECISIONS.md` (и другие документы, если нужно), чтобы новый чат продолжил без пересказа.
