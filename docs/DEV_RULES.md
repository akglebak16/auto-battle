# Правила разработки

## Код
- TypeScript strict, ES-модули, без фреймворков. Сборка — Vite (`npm run dev` / `npm run build`).
- Комментарии и идентификаторы — английские. **Все тексты для игрока — на двух языках**: `L('рус', 'eng')` из `src/i18n.ts` прямо на месте (в `data.ts`, `skills.ts`, `game.ts`, `ui.ts`, `render.ts`). С переменными — шаблоны в обеих частях: ``L(`Волна ${n}`, `Wave ${n}`)``. Английское множественное число — вручную (`${n > 1 ? 's' : ''}`).
- Статичный текст в `index.html` — русский в разметке + `data-en="…"` (заменяет innerHTML) и `data-tip-en="…"` (заменяет подсказку). Текст в CSS (`content: '…'`) — переопределение `html[lang=en] … { content: '…' }`.
- Логика не должна зависеть от текста (имён, названий) — только от `id`.
- Проверка, что ничего не забыто: `grep -nP "[А-Яа-яЁё]" src/*.ts | grep -v "L("` — должны остаться только комментарии.
- Стиль как в существующем коде: компактный, плотный, с короткими поясняющими комментариями «зачем», а не «что». Не переформатировать чужие участки без нужды.
- `game.ts`/`data.ts`/`skills.ts` — без DOM, canvas, `window`, `Date.now()`, `Math.random()`. Случайность — `this.rnd()`, время — `this.time`/`dt`. Иначе ломается `scripts/sim.ts` и детерминизм.
- Числа раскладки поля — только через константы из начала `game.ts` (`WALL_X`, `LANE_Y0`, `GATE_Y0` …), не хардкодить координаты в render/ui.
- Новые параметры баланса — именованные константы с комментарием (что и почему такое значение).
- `ui.ts`: действия кнопок — через `data-act`/`data-arg` и `onClick`. Элементы, которые перерисовываются в `tick()` (панель героев, заклинания, полоска босса), реагируют на `pointerdown`, а не на `click`.
- Подсказки — через `tip('<b>…</b>…')` (атрибут `data-tip`).
- Сохраняемые структуры (`Meta`, забег) — только обратно совместимые изменения.

## Как добавить…
- **Героя**: `HEROES` в `data.ts` (роль, статы, описание) → умения в `skills.ts` (`hero: '<id>'`, эволюции) → арт в `UNIT_ART` (`art.ts`) и иконка → при закрытом герое — `LOCKED_HEROES` + узел в `META_UPGRADES` → проверить пост по умолчанию (`HERO_POSTS` раздаются по дальности) → `sim` с этим героем первым (`npm run sim -- 25 <id> 4`).
- **Врага**: `ENEMIES` (радиус, скорость, дальность, `ignoresHeroes`, награды) → `UNLOCKS` (с какой волны, вес, рост) → `UNIT_ART` → если особая механика — в `updateEnemies` → `sim`.
- **Предмет/рецепт**: `ITEMS` (tier, cost, mods, effect) / `RECIPES`. Эффекты — `ItemEffect` + обработка в `game.ts`.
- **Заклинание**: `SPELLS` (key, cd, radius, node) → узел Цитадели → `castSpell` в `game.ts` → цвет прицела в `ui.aimAt` → бот в `sim.ts`, если заклинание влияет на баланс.
- **Узел Цитадели**: `META_UPGRADES` (branch, req, max, baseCost, growth, desc) → эффект через `this.up('<id>')` в `game.ts`.
- **Реликвию/синергию/событие**: `RELICS`/`SYNERGIES` в `data.ts`, логика — `hasRelic`/`hasSyn` в `game.ts`, события — в блоке событий `game.ts` и окне в `ui.ts`.
- **Иконку** (предмет, навык, заклинание, приказ): функция `@icon('<kind>_<id>')` в `scripts/gen-icons.py` → `python scripts/gen-icons.py` → в данных `icon: ic('<kind>', '<id>')`. Нет иконки — игра падает при загрузке с `missing icon …` (это проверка покрытия). Эмодзи для этих четырёх видов не использовать.
- **Биом**: `BIOMES` + `setBiome` (река, мосты), фон в `render.ts` (фильтр земли, погода, свет).

## Процесс задачи
1. Прочитать `CLAUDE.md` → `docs/STATE.md` → `docs/LESSONS.md` → нужные разделы `ARCHITECTURE.md`.
2. Воспроизвести/посмотреть (игра в браузере, замер, скриншот). Для багов — сначала доказать причину (замер, лог), потом чинить.
3. Если задача большая или неоднозначная — коротко согласовать план с владельцем.
4. Делать маленькими проверяемыми шагами; после каждого — `tsc`.
5. Проверки из `TESTING.md` → обновить документы (протокол в `CLAUDE.md`) → коммит.
