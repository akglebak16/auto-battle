# Архитектура

Обновлено: 2026-11-12 (v0.12, замок слева).

## Модули (`src/`)
| Файл | Отвечает за | Можно трогать DOM/canvas? |
|---|---|---|
| `main.ts` | Точка входа: создаёт `Game`, `Renderer`, `UI`; сохранения в `localStorage`; управление камерой (перетаскивание, колесо, стрелки, H); игровой цикл с фиксированным шагом 1/60 с | да |
| `game.ts` | **Вся симуляция**: фазы, волны, герои, враги, снаряды, башни, заклинания, события, реликвии, экономика, Цитадель, сохранение забега. Константы раскладки поля | **нет** (запускается headless в `scripts/sim.ts`) |
| `data.ts` | Данные: герои, предметы, рецепты, редкости, узлы Цитадели, реликвии, синергии, биомы, заклинания, враги, формулы волн и масштабирования | нет |
| `skills.ts` | Умения героев (карты уровня), ранги, эволюции, `rollCards` | нет |
| `render.ts` | Canvas: камера (`Camera`), предрисованный фон (тайлы, дорога, река, стена, замок, башни), юниты, эффекты, свет, погода, кровь | только canvas |
| `ui.ts` | DOM-оверлеи: HUD, панель героев, заклинания, лагерь, Цитадель, меню, события, обучение, подсказки, горячие клавиши, клики по полю (приказы) | да |
| `art.ts` / `artData.ts` | Загрузка спрайтов Tiny Swords (base64 в `artData.ts`, генерится `scripts/gen-art.py` из `assets/ts/`), анимации юнитов, UI-скин | да |
| `sprites.ts` | Старые векторные спрайты (запасной вид, пока арт не загрузился), иконки героев | canvas |
| `sound.ts` | Процедурные звуки и музыка (WebAudio), состояния музыки по фазе/боссу/комбо | WebAudio |
| `settings.ts` | Настройки игрока (громкость, размер UI, тряска, кровь, числа, свет) | localStorage |
| `i18n.ts` | Язык (`ru`/`en`): определяется **один раз при загрузке** (сохранённый выбор, иначе язык браузера; без `localStorage` — русский, как в `sim.ts`). `L(ru, en)`, `GAME_TITLE`. Смена языка = запись ключа и перезагрузка страницы | читает localStorage/navigator, без DOM |
| `style.css` | Весь CSS, включая скин `html.skin …` (переопределения в конце файла) | — |

`scripts/sim.ts` — бот, играющий забеги без графики (баланс). `scripts/dbgm.ts` — проверка баланса с заданными узлами Цитадели. `electron/main.cjs` — окно Electron, грузит `dist/index.html`.

## Поток данных
`main.ts` → каждый кадр: `game.update(1/60)` N раз (скорость 1×/2×/4×, замедление при убийстве босса) → `renderer.draw(game)` → `ui.tick()`.
`game.events.onChange` → `ui.refresh()` (полная перерисовка DOM-панелей). `game.events.onSound` → `sound.play`.
`ui.tick()` перерисовывает панель героев/заклинаний/босса **каждые 6 кадров** через `innerHTML` (см. LESSONS: клики по этим панелям ловить на `pointerdown`).

## Фазы
`menu` → `battle` (волна) → `shop` (лагерь между волнами; события, выбор карт умений) → … → `gameover`. Сохранение забега — автосейв в лагере.

## Мир и координаты (замок слева, орда справа)
Все константы — в начале `game.ts`.
- Мир `WORLD_W × WORLD_H = 1600 × 900`. Ось X — от замка (слева) к врагам (справа). Ось Y — поперёк поля.
- Стена: передний край `WALL_X = 150`. Ворота по Y: `GATE_Y0..GATE_Y1 = 310..590`. Башни `TOWERS` за стеной (x=92, y=250 и 712), дальность `TOWER_RANGE = 470`.
- Полоса боя по Y: `LANE_Y0..LANE_Y1 = 120..800` (сверху и снизу экран закрыт HUD). Юниты и точки сбора зажимаются в неё.
- Враги появляются за правым краем (`FIELD_RIGHT + 30..90`), 20% — с верхнего/нижнего края у правой кромки.
- Дорога — кубическая Безье `ROAD` от правого края к воротам; `roadY(x)` даёт её y.
- Река — вертикальная полоса `river.x0..x1 = 900..960`, мосты — список y (`BRIDGE_HALF = 34`). Переход вне моста вдвое медленнее; на Зимнем перевале река замёрзла. Обход — `waypoint()`.
- Посты героев по умолчанию `HERO_POSTS`: танк (x=590, y=450), стрелки за ним на флангах (420, 320) и (420, 580). Раздаются по возрастанию дальности атаки.
- Камера (`render.ts`): логический экран 1280×720 по высоте (`VIEW_H = 720`, ширина по соотношению сторон 1.25–2.6). На минимальном зуме всё поле влезает и **камера стоит** (центрирована); при приближении панорамирует только внутри поля. Фон рисуется с запасом `BG_PAD = 420` по X и `BG_PAD_Y = 260` по Y, чтобы на любом экране не было чёрных полос.

## ИИ героев (`updateHeroes`)
- Цели ищутся вокруг **поста** (`homeX/homeY`), а не вокруг героя. Ретаргет каждые 0,25 с.
- Агр: ближник `MELEE_AGGRO = 250`; стрелок/маг — `range + 70`. Поводок (как далеко от поста можно отойти в бою): ближник `агр + 180`, стрелок `агр + 30`. Если цель вне поводка — герой идёт к посту (не замирает).
- Ближник охраняет стрелков: `guardTarget()` — враг в 75 px от союзника-стрелка, стоящего в радиусе `агр + 120` от поста ближника, приоритетнее обычной цели.
- Стрелки отходят от гоблинов-ближников (kiting) к стене, но не дальше 80 px за свой пост — дальше только в сторону.
- Приказы игрока: `rally(hero|null, x, y)` — новый пост и флажок (`rallied`), герой сначала доходит (`marching`, без боя), потом держит точку; `focusEnemy(hero, enemy)` — атаковать конкретного врага, преследуя без поводка (`focus`); `resetPosts()` — все на посты по умолчанию.
- Приход нового героя (`addHero` → `layoutHeroes(joined)`) ставит на пост только новичка; остальные сохраняют свои точки сбора.
- Если у поста никого нет, `zoneTarget()` берёт ближайшего врага на стороне замка (левее `zoneX()` = край реки) или стрелка из-за реки, который достаёт до героя (`range + 60`); цель считается преследуемой (`chase`) — без возврата по поводку. Герои не стоят на месте, но и не уходят на чужую половину.
- Скелеты Морры (`minion`) просто охотятся на ближайшего врага и живут ограниченное время.

## ИИ врагов (`updateEnemies`)
- Боссы: `bossAbility()` по таймеру `special` со способностями-«кастами» (`startCast` — телеграф). Владыка орды (`overlord`) считает фазу по доле HP (`e.ph`: >66%, >33%, ниже), смена фазы запускает каст сразу; общие помощники `stomp`, `fireballs` (метки на героях, урон через 1,3 с), `callHorde`. Мастер кузни (`forgemaster`) чередует бочки-подрывники и удар молота. Орк-шаман — `shamanWard` (броня союзникам 4 с). Поджигатель при смерти жжёт героев рядом (в `damageEnemy`, ветка смерти). Тролль — `def.regen`.
- Кривая сложности (`data.ts`): `waveHpScale = rawHpScale × earlyBoost × spike`, `waveSize` — тоже `earlyBoost`/`spike`; константы описаны в DECISIONS («Ужесточение старта»).
- Спрайты боссов — `scripts/gen-bosses.py` (Pillow, без внешних ассетов): правишь рисунок → `python scripts/gen-bosses.py` → `python scripts/gen-art.py` (пересборка `artData.ts`).
- Победа: `endWave()` на `wave >= FINAL_WAVE` вызывает `winRun()` (`Game.won`, `Meta.wins`, бонус алмазов).
- Локации: `biomePlan` (6 блоков по 5 волн), `enterLocation(wave)` в `endWave()`; `setBiome` задаёт реку и множители (`BIOME_MOVE/RANGE/FOE`).
- Большинство охотится на ближайшего живого героя где угодно на поле; `ignoresHeroes` (подрывники) бегут к стене и дерутся, только если герой на пути.
- Без цели — марш к воротам: цель по Y зажата в `GATE_Y0..GATE_Y1`, остановка на `WALL_X + radius + range`, затем бьют стену (`hitCastle(dmg, y)`).
- Скорость = `def.speed × MARCH_SPEED (1.15) × элита × биом × бафф полководца × (1 − замедление)`.
- Боссы каждые 5 волн по кругу: Король гоблинов → Огр-таран → Шаман-некромант → Гоблин-полководец (способности — в `game.ts`, телеграфы перед ударами).
- Поиск соседей — пространственная сетка `CELL = 48` (`forEachNear`, `nearestEnemy`).

## Мета и экономика (кратко)
Золото — на забег (лавка, ремонт, приказы, башни). Алмазы 💎 — постоянная валюта (с каждого врага), тратится в Цитадели (4 ветки: Отряд, Твердыня, Магия, Казна). Второй/третий герой приходят на уровне отряда 3 и 8 (если открыты). Предметы: 4 слота, 4 редкости, 3 одинаковых → слияние, рецепты из пар. Реликвии и синергии — пассивки на забег. Заклинания Q/W/E/R открываются в ветке Магия.

## Сохранения (`localStorage`)
| Ключ | Что |
|---|---|
| `oplot-save-v2` | `Meta`: алмазы (в коде `shards`), узлы Цитадели, рекорд, число забегов, стартовый герой |
| `oplot-run-v1` | Сериализованный текущий забег (продолжить из меню) |
| `oplot-settings-v1` | Настройки |
| `oplot.tut` | Показанные подсказки обучения |
| `oplot-lang` | Выбранный язык (`ru`/`en`); нет ключа — по языку браузера |
Менять формат — только с миграцией или новым ключом (`-v3`).
