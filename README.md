# Оплот: Осада

2D автобаттлер-рогалик для ПК. Гоблинская орда идёт сверху карты на ваш замок внизу: десятки врагов
в начале, сотни к 15–20 волне. Герои сражаются сами, а вы между волнами выбираете им улучшения
и снаряжение.

## Правила забега

- Забег начинается с **одного случайного героя**. Второй и третий присоединяются (тоже случайно),
  когда уровень отряда (сумма уровней героев) достигнет **3** и **8**.
- Каждый новый уровень героя — выбор **1 из 3 карточек**: собственные умения героя (до ранга 3)
  или общие усиления (сила, живучесть, проворство).
- Гоблины сначала атакуют **героев**. Замок они штурмуют, только когда все герои пали.
- Между волнами: лавка предметов, тренировка за золото, починка стен, улучшение башен.
- **Снаряжение сохраняется между забегами** (арсенал). Купленный предмет остаётся навсегда:
  надет на героя или лежит в арсенале. Его можно снять, надеть на другого героя или продать.
- Если замок пал, забег окончен. Новый забег снова начинается с одного героя, но со всем арсеналом.

## Герои и умения

| Герой | Умения (авто) | Пассивки |
|---|---|---|
| Бран, Страж ворот | Удар щитом (урон + оглушение), Провокация (враги бьют его, +броня) | Шипы (отражение урона), Несокрушимость (+HP, реген) |
| Ива, Лучница | Залп (стрелы по нескольким целям), Пробивающая стрела (по линии) | Меткость (криты), Мультивыстрел |
| Оррин, Пиромант | Метеор (в самую плотную толпу), Огненное кольцо (взрыв + отбрасывание) | Поджог (урон со временем), Пекло (радиус и урон) |

## Враги

Урон каждого типа фиксированный, сложность растёт за счёт количества, здоровья и новых типов:
гоблин-рубака (1), гоблин на волке (2), гоблин-шаман (3, стреляет), хобгоблин (4),
гоблин-латник (7, тяжёлая броня), гоблин-вожак (11), король гоблинов (каждая 5-я волна).
Новые типы добавляются в `src/data.ts` → `ENEMIES` и `UNLOCKS`, а их внешний вид — в `src/sprites.ts`.

## Управление

Камера: перетаскивание мышью, колесо — масштаб, WASD/стрелки, H — к замку.
Пробел — пауза, 1/2/3 — скорость x1/x2/x4, M — звук, клик по герою — выбрать его. F11 в .exe — полный экран.

## Что нового (v0.2)

- **Эволюции умений.** Когда оба исходных умения героя на максимальном ранге, в карточках появляется оранжевая
  эволюция: Сотрясение земли (Бран), Возмездие (Бран), Шквал стрел (Ива), Смертельный глаз (Ива),
  Огненный дождь (Оррин), Лесной пожар (Оррин). Общие карточки пополнились: Закалка, Жажда крови, Сосредоточение.
- **Особые предметы** (эффект растёт с редкостью): Ледяной осколок, Топор палача, Молот грома, Перо феникса, Кошель вора.
- **Лавка:** закрепление предметов (🔒), скидка −40% на один предмет, цена обновления растёт, шансы редкостей зависят от волны.
- **Приказы** на одну волну: Боевой рог, Кипящая смола, Лучники на стенах, Награда за головы (цена растёт с волной).
- **Предпросмотр волны** в лавке, отчёт о потерях после волны.
- **Враги:** гоблин-подрывник (с 8-й волны бежит к стене и взрывается), рост урона и здоровья врагов к поздним волнам.
- **Сочность:** тряска экрана, частицы смерти, цифры урона, анимации атак героев.
- **Баланс** проверяется ботом: `npm run sim -- 30 random 4`.

## Запуск

Нужен Node.js 18+ (`node -v`).

```bash
npm install
npm run dev          # игра в браузере: http://localhost:5199
npm run desktop      # игра в отдельном окне (Electron)
npm run build:exe    # собрать release/OplotSiege-win32-x64/OplotSiege.exe
```

Папку `release/OplotSiege-win32-x64` можно заархивировать и передать другому: внутри `OplotSiege.exe`
и всё нужное для запуска. Прогресс (арсенал, рекорд) хранится в профиле Windows, а не в папке игры.

## Проверки

```bash
npm run typecheck                      # проверка типов TypeScript
npm run sim                            # бот играет 1 забег до 25 волны без графики
npm run sim -- 30 random 3             # 3 забега подряд до 30 волны: видно, как помогает арсенал
npm run sim -- 20 warden               # забег, который начинается со Стража
```

## Устройство

| Файл | Что внутри |
|---|---|
| `src/data.ts` | Герои, предметы, враги, открытие типов врагов по волнам, состав волн |
| `src/skills.ts` | Умения героев и карточки улучшений (числа в `SK`) |
| `src/game.ts` | Симуляция: бой, умения, цели, золото, опыт, забеги, арсенал. Без DOM, работает и в `sim` |
| `src/sprites.ts` | «Модельки»: герои и гоблины рисуются кодом один раз в маленькие картинки |
| `src/render.ts` | Отрисовка карты, замка, юнитов и эффектов; камера |
| `src/sound.ts` | Звуки, синтезированные через Web Audio (без аудиофайлов) |
| `src/ui.ts` | HUD, меню, карточки, лавка и арсенал, экран поражения |
| `src/main.ts` | Игровой цикл (фиксированный шаг 1/60 с), управление камерой, сохранение |
| `electron/main.cjs` | Окно для .exe |
| `scripts/sim.ts` | Безграфическая симуляция с ботом |

Производительность: враги берутся из пула объектов, поиск целей идёт по сетке 48×48 px, спрайты
рисуются заранее, отрисовываются только юниты в кадре, частые звуки ограничены по частоте.
При ~450 гоблинах на поле логика занимает ~0,15 мс на шаг.
