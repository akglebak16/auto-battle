
## Что нового (v0.3)
- **Цитадель — дерево из 4 веток** (Отряд, Твердыня, Магия, Казна). Узел открывается после родителя. Второй и третий герой теперь открываются в дереве.
- **Алмазы 💎 падают с каждого врага** (над убитым видно «+N🪙 +N💎»), остаются даже после поражения. Цены дерева рассчитаны примерно на 20 забегов.
- **Магия игрока**: Огненный дождь (Q), Ледяные оковы (W), Благословение (E). Q/W — затем клик по полю. Esc — отмена.
- Всё поле видно без прокрутки камеры; трупы остаются лежать полупрозрачными до конца волны.
- Стрелки и маг отходят от гоблинов, стоят за танком.
- Баланс: ослаблен первый Король (5 волна), поздние волны и экономика больше не разгоняются как снежный ком, пересмотрены цены редкостей и предметов.
- `bun scripts/dbgm.ts '{"slot2":1}' 0 8` — проверка баланса с заданными улучшениями Цитадели.

## Что нового (v0.12) — замок слева, управление героями
- **Замок теперь слева, орда идёт справа.** Поле во всю ширину экрана: путь врагов вырос примерно с 810 до 1400 px, у героев есть место встать впереди. Стена, ворота, башни и факелы идут по левому краю, река с мостами пересекает поле сверху вниз.
- **Камера больше не уезжает в пустую траву.** Когда видно всё поле, она стоит на месте. После приближения (колесо) прокручивается только в пределах поля.
- **Бран (и любой ближник) снова танкует.** Агр 250 px вокруг поста вместо 150. Защищает стрелков: гоблин рядом с союзником становится его целью.
- **Посты дальше от стены.** Танк впереди, стрелки за ним на флангах. Стрелки при отходе не уходят далеко за свой пост. Герой больше не «замерзает», если цель вне поводка: он возвращается на пост.
- **Выбор героя по карточкам работает всегда.** Раньше клики терялись из-за перерисовки панели. Двойной клик по карточке — камера к герою.
- **Приказы:** клик по герою (или по карточке), затем по земле — он идёт туда и держит эту точку (сначала доходит, потом дерётся). Клик по врагу — атакует именно его (красная метка). Esc или ПКМ — отмена. Случайный клик по полю никого не двигает. Кнопка «↺ на посты» возвращает всех на места.
- Приход нового героя посреди боя больше не телепортирует остальных и не сбрасывает их точки.
- Карточки героев — в ряд внизу слева, на узких экранах они уже.

## Что нового (v0.14)
- **У игры есть конец — 30 волн.** На 30-й волне — финальный босс **Владыка орды** с тремя фазами (топот, огненный залп по героям, призыв орды, ярость), затем экран победы с бонусом алмазов (первая победа +600, дальше +300). В шапке — «Волна N/30».
- **Новые враги с 16-й волны:** Тролль (лечится сам), Гоблин-осадник (бьёт по стене издалека), Орк-шаман (даёт союзникам броню), Гоблин-поджигатель (взрывается огнём). **25-я волна** — мини-босс Мастер осадной кузни.
- **Локация меняется каждые 5 волн.** Две новые: Песчаная пустошь (зной) и Пепельные земли (последние 5 волн, лава вместо реки). Порядок случайный, у каждой свои бонусы.
- **Герои не стоят без дела:** они сами бьют любого врага на своей стороне реки и переходят через реку, только если оттуда по ним стреляют.
- **Первые забеги — испытание.** Без Цитадели враги заметно крепче: первые 1–3 волны обычно не проходятся, и это нормально — каждый забег приносит минимум 30 💎 (плюс за убитых и пройденные волны), после 2–4 забегов хватает на «Второго героя» и другие первые усиления. Сложность дальше растёт плавно, с неровными «стенками» (не строго каждая третья волна).
- **Новые модели боссов:** у Короля гоблинов, Огра, Некроманта, Полководца, Мастера кузни и Владыки орды свои нарисованные спрайты с анимацией простоя, бега и удара.
- **Цитадель:** ветки дерева больше не вылезают за свои рамки.
- **Аудит баланса:** Тролль больше не «неубиваемый» (лечится на четверть силы, пока его бьют) — это была главная стенка на 16–20 волнах; Лучница стала сильнее (её стрелы бьют по небольшой площади, +HP/урон); заклинания Огненный дождь (+23%) и Ледяные оковы (+29%) бьют сильнее — ветка «Магия» теперь реально ощущается.
- **Боссы охотятся за героями** (Огр-таран больше не бьёт одну стену), радиус их ударов вокруг себя ×2, новый скилл **«Громовой удар»**: на героях появляются фиолетовые метки, затем молния и электрический взрыв оглушают всех в круге (можно успеть убежать). Оглушённые герои теперь со звёздами над головой.
- **Кривая сложности перестроена** под ступенчатый рост: первые забеги — волны 1–5, потом каждая покупка в Цитадели заметно двигает вперёд; сильная Цитадель (≈75%+) — победа на 30-й волне. Второй герой стоит 150 алмазов, третий — 800; за ранние забеги дают больше алмазов; тролль слабее.
- **Интерфейс на узких экранах (4:3, 5:4):** лагерь в три колонки без обрезанных кнопок, видна кнопка паузы, подсказки не закрывают заголовок уровня.
- Баланс: рост здоровья врагов после 15-й волны выровнен, лимит волны — 700 врагов; Полководец лечит орду слабее; в поздних волнах орда начинает штурм стены позже.
