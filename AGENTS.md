# Инструкции для ИИ-агентов

Единый источник правил проекта — **[CLAUDE.md](CLAUDE.md)** (конституция) и папка **[docs/](docs/)**.
Любой агент (Claude, Cursor, Copilot, Codex и др.) перед работой читает `CLAUDE.md`, затем `docs/STATE.md` и `docs/LESSONS.md`, а в конце задачи обновляет документы по протоколу самообучения из `CLAUDE.md`.
